## 🤖 BloxBot™ Interactive AI Guide & Research Copilot

**BloxBot™** is an animated, voice-integrated research companion designed with a Roblox-inspired 3D aesthetic and full scientific reasoning capabilities.

### 🎯 Key Capabilities of BloxBot™

1. **Multi-Document Ingestion Across ANY Format**:
   - Attach single or multiple files simultaneously (PDF, Microsoft Word `.docx`/`.doc`, Excel `.xlsx`/`.xls`, SPSS `.sav`/`.sps`, CSV, TSV, JSON, Markdown, LaTeX `.tex`/`.bib`, TXT, Python/R/SQL code files, and binary formats).
   - Drag-and-drop support with real-time file queue, format badges, and individual file removal.
   - Cross-document corpus harmonization and batch synthesis across all attached files.

2. **3D Expressive Emotion Engine**:
   - Interactive animated avatar responding dynamically with visual facial expressions:
     - `idle`: Observant blinking and status scanning.
     - `thinking`: Rotating radar antennas and calculation sweeps.
     - `happy`: Neon celebratory pulses upon hypothesis breakthroughs.
     - `excited`: High-energy particle sparkles when grant funding or strong correlations are identified.
     - `shocked`: Expressive warnings when data contradictions or p-hacking risks are flagged.
     - `error`: Diagnostics mode with immediate troubleshooting options.

3. **Autonomous Deep-Research Operations Matrix**:
   - ⚡ **Auto-Run IBM SPSS Statistical Analysis**: Parses uploaded datasets, executes inferential tests, produces `.sps` syntax scripts, and outputs APA 7th-compliant tables.
   - 🧬 **Formulate Novel Testable Hypotheses**: Cross-references ingested literature against foundational databases to extract bold, high-novelty hypotheses.
   - 🌉 **Synthesize Interdisciplinary Bridges**: Maps analogies between distant scientific fields (e.g., fluid dynamics $\leftrightarrow$ viral capsid assembly).
   - 📄 **Deep Literature Review & Meta-Synthesis**: Extracts consensus findings, methodology comparisons, and unresolved disputes across multiple papers.
   - 🎓 **Generate Academic Thesis Chapters**: Produces structured thesis sections formatted with citations, methodologies, LaTeX formulas, and SPSS syntax.
   - 🧪 **Design Experimental Lab Protocols**: Auto-generates complete step-by-step laboratory plans with control groups, estimated costs, and required reagents.
   - 💰 **Search & Match Grant Solicitations**: Matches documents and research abstracts with open NIH, NSF, and Horizon Europe funding opportunities.
   - 🔍 **Contradiction Resolution Engine**: Pinpoints conflicting claims between papers and outlines resolving experiments.

4. **Speech Synthesis (TTS) & Voice Recognition**:
   - Hands-free voice input via Web Speech API recognition.
   - Real-time robotic speech synthesis for research updates and briefings.
   - Dedicated voice toggle, playback controls, and volume calibration.

5. **Instant Document & Dossier Export Suite**:
   - Export any BloxBot conversation, SPSS package, or thesis draft into **PDF**, **Markdown (.md)**, **Plain Text (.txt)**, or **JSON**.
   - Built-in document management modal displaying export history, word counts, and direct clipboard copying.

6. **Automated Support Ticket Dispatch & System Telemetry**:
   - In case of network drops or parsing hiccups, BloxBot features a **"Notify Team"** button that sends instant error diagnostics to the administrative logging channel.

## 🧬 Multi-Agent Evolutionary Hypothesis Tournament

Synapse OS runs a collaborative tournament between specialized AI agents to generate, critique, and refine scientific hypotheses.

```
┌────────────────────────┐     ┌────────────────────────┐     ┌────────────────────────┐
│ LITERATURE AGENT       │────►│ HYPOTHESIS GENERATOR   │────►│ CRITIC & VERIFIER      │
│ Ingests papers & data  │     │ Formulates bold claims │     │ Stress-tests novelty   │
└────────────────────────┘     └────────────────────────┘     └───────────┬────────────┘
                                                                          │
                                                                          ▼
┌────────────────────────┐     ┌────────────────────────┐     ┌────────────────────────┐
│ EXPERIMENTAL SIMULATOR │◄────│ DVS RANKING ENGINE     │◄────│ CITATION MATCHER       │
│ Calculates cost & time │     │ Scores 6 DVS metrics   │     │ Links foundational DOI │
└────────────────────────┘     └────────────────────────┘     └────────────────────────┘
```

### 🏆 Discovery Value Score (DVS) Algorithm

Every hypothesis is evaluated on a rigorous multi-dimensional index ($0 - 100$):

$$\text{DVS} = w_1 \cdot \text{Novelty} + w_2 \cdot \text{Impact} + w_3 \cdot \text{Feasibility} - w_4 \cdot \text{Cost} - w_5 \cdot \text{Time} + w_6 \cdot \text{Influence}$$

- **Contradiction Resolution Matrix**: Identifies direct conflicting claims between Paper A and Paper B, proposing an empirical resolving experiment.
- **Automated Experimental Protocol Generator**: Recommends exact independent/dependent variables, control groups, required reagents, and safety considerations.
- **Laboratory Cost & Timeline Estimator**: Calculates estimated compute, reagents, and personnel budgets with failure probability metrics.

## 📊 IBM SPSS® Statistical Studio & APA 7th Reporting

A full-fledged statistical analysis and automation suite built for empirical researchers.

### 🧪 Supported Statistical Tests

| Analysis Suite | Use Case | Generated APA 7th Output |
| :--- | :--- | :--- |
| **Descriptives & Normality** | Mean, SD, Skewness, Kurtosis, Shapiro-Wilk | $M = 45.2, SD = 8.4$ |
| **Independent Samples t-Test** | Comparing two independent treatment groups | $t(58) = 3.42, p = .001, d = 0.88$ |
| **One-Way ANOVA** | Multi-group experimental variance | $F(2, 87) = 14.28, p < .001, \eta_p^2 = .25$ |
| **Factorial ANOVA (2x2, 3x2)** | Main effects and interaction terms | $F(1, 116) = 6.84, p = .010, \eta_p^2 = .06$ |
| **Multiple Linear Regression** | Predictor models, $R^2$, and $F$-tests | $F(3, 96) = 28.51, p < .001, R^2 = .47$ |
| **Pearson & Spearman Correlation** | Bi-variate linear and non-parametric associations | $r(118) = .58, p < .001$ |
| **Cronbach's Alpha Reliability** | Survey scale internal consistency | $\alpha = .89$ (High Reliability) |
| **Chi-Square ($\chi^2$) Independence** | Categorical frequency & contingency analysis | $\chi^2(2, N = 200) = 18.42, p < .001, V = .30$ |
| **PCA & Factor Analysis** | Dimensionality reduction, loadings & scree plot | KMO $= .84$, Bartlett's $p < .001$ |

### 💎 SPSS Studio Features

- **Interactive Dataset Editor & Variable Inspector**: Configure variable names, labels, measurement scales (`Scale`, `Ordinal`, `Nominal`), decimal precision, value labels, and missing value indicators.
- **Native IBM SPSS `.sps` Syntax Generator**: Generates fully valid, executable SPSS command syntax ready to copy and paste directly into IBM SPSS Statistics.
- **APA 7th Publication-Ready Table Generator**: Generates formatted statistical tables with mean comparisons, standard errors, and confidence intervals ($95\%\text{ CI}$).

## 🚀 Quick Start & Installation

### Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher
- **Google Gemini API Key**: Obtainable from [Google AI Studio](https://aistudio.google.com/)

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/scientific-discovery-os.git
cd scientific-discovery-os
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a `.env` file in the root directory:
```bash
cp .env.example .env
```
Fill in your Gemini API key and optional Firebase configuration:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 4. Run Development Server
```bash
npm run dev
```
The application will launch at `http://localhost:3000`.

### 5. Build for Production
```bash
npm run build
npm start
```
